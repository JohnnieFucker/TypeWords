# WordsBattle

背单词、养仙宠、和朋友切磋。项目基于 [TypeWords](https://github.com/zyronon/TypeWords)，保留单词练习与本地学习进度，并增加微信登录和仙宠玩法。

## 运行

需要 Node.js 22.13 或更高版本：

```bash
pnpm install
pnpm dev
```

打开 `http://localhost:5567`。不登录也可以在本机学习；仙宠、灵物和切磋需要微信登录并连接同一个服务端。静态生成的站点不包含账号和游戏接口。

正式部署时，先在服务器安装 PM2（例如 `npm install -g pm2@latest`），并在项目根目录配置 `.env.production`（可参考 `.env.production.example`），然后运行：

```bash
pnpm install --frozen-lockfile
pnpm build
pnpm start
```

`pnpm start` 使用 `pm2.json` 启动单个守护进程，并在 Node.js 启动前读取 `.env.production`。启动命令应从项目根目录执行；系统环境变量优先于文件中的同名配置。常用管理命令：

```bash
pm2 status
pm2 logs wordsbattle
pm2 restart pm2.json
pm2 stop wordsbattle
```

如需开机自启，先运行 `pm2 startup` 并执行其提示的命令，再运行 `pm2 save`。该服务需要持久化服务器，不能用 `pnpm generate` 的静态产物替代。


## 微信登录

需要已开通网页授权的微信公众号，并在公众号后台配置网页授权域名，按微信要求将域名验证文件放到站点根目录。开发环境编辑项目根目录的 `.env`，正式部署编辑 `.env.production`，填写 `WECHAT_APP_ID`、`WECHAT_APP_SECRET` 和 `WECHAT_CALLBACK_URL`；两个文件均已加入 `.gitignore`。如果文件不存在，可分别从 `.env.example` 和 `.env.production.example` 复制。

回调地址需要是手机可访问的 HTTPS 地址，例如 `https://你的域名/api/auth/wechat/callback`；使用部署子路径时，在 `/api` 前加入子路径。生产启动命令从启动目录读取 `.env.production`，系统环境变量优先。不要提交真实密钥。电脑显示一次性二维码，手机通过微信扫码授权后，电脑建立登录会话。本机 `localhost` 无法单独完成微信授权。

## 仙宠玩法

首次微信登录随机获得金、木、水、火、土之一的灵兽，并获赠一份行囊和一张寻缘符。每日完成学习并同步后，获得一件随机照料道具和 25 点修为：普通 70%、优良 25%、珍稀 5%。每连续学习 3 天额外获得一次同概率照料道具。普通学习不再掉落战斗属性道具，已有旧道具仍可使用。

- **温和照料**：各灵兽独立拥有饱食、洁净和心情；饱食、洁净、心情分别按服务器时间每 4、6、8 小时下降 1 点，最低保留 20，不会死亡或丢失。投喂、清洁可恢复状态；状态会适度影响切磋发挥。每天问候仙宠可增加心情，并获得一份行囊和一张寻缘符。
- **灵兽寻缘**：消耗寻缘符，有机会遇见并收服灵兽；重复相遇可增加该灵兽修为。图鉴中可切换已收服的伙伴，各伙伴的修为、属性和照料状态独立保存。达到 5 级进入化灵阶段。
- **离线旅行**：消耗一份行囊出发，约 1 小时后归来并带回纪念品、旅途记录和 15 点修为。旅行按服务器时间计时，离线期间也会继续；重新打开仙宠页面时结算。旅行期间无法切换同行伙伴、使用灵物或切磋。
- **异步切磋**：每天最多发起 5 次，无需双方同时在线。金克木、木克土、土克水、水克火、火克金，相克方的切磋力量增加 20%；胜负还取决于属性、照料状态和少量随机值。

学习记录延迟同步时，可补领最近 7 天的未领取奖励；日期以北京时间为准。学习结果由客户端提交，当前没有防作弊验证，不适合用于有奖励的正式竞技。

## 数据保存

单词练习和设置保存在浏览器；完成学习后，登录用户的学习进度同步到服务端。仙宠、道具和对战记录保存在 SQLite 中。默认数据库位于 `.data/typewords.sqlite`，可通过 `.env` 中的 `TYPEWORDS_DATA_DIR` 指定持久化目录。部署时请持久化并备份该目录，包括 SQLite 的 WAL 文件。沿用原数据库文件名以保留现有数据。

跨设备合并以较大的词典学习位置和较新的单词复习状态为准；删除单词或回退学习位置目前不会同步。自定义词典仅同步单词原文，不同步释义、例句等内容。
